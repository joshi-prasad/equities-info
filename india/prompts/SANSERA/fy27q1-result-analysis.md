# ANALYST SENTIMENT

Analyse **only external analysts/participants who asked questions during the latest earnings call**.

Exclude management, moderator, employees, opening remarks, and unidentified participants unless clearly identifiable as analysts/institutional participants.

**Count analysts, not questions.** If an analyst asks multiple questions, count them once for sentiment percentages.

Classify each analyst based **only on explicit wording**:

* **Explicitly Congratulatory** — explicitly congratulates management/results.
* **Clearly Positive** — explicitly expresses satisfaction/appreciation without saying “congratulations”.
* **Neutral / Information-Seeking**
* **Cautious / Skeptical**
* **Clearly Negative**

Do **not** infer sentiment from the subject of a question, such as growth, margins, approvals, capacity, customers, or future revenue. A generic “thank you” is not positive.

If analyst identity is unclear, state **“NOT SUFFICIENTLY DISCLOSED.”**

#### Analyst Sentiment Summary

| Measure                                  | Count |
| ---------------------------------------- | ----: |
| Analysts who asked at least one question |       |
| Total analyst questions                  |       |
| Analysts explicitly congratulatory       |       |
| Analysts clearly positive                |       |
| Analysts with any positive reaction      |       |

Calculate:

**Explicit Congratulations %**
= Explicitly Congratulatory Analysts ÷ Analysts Who Asked Questions × 100

**Positive Reaction %**
= Analysts with Any Positive Reaction ÷ Analysts Who Asked Questions × 100

Where **Any Positive Reaction = Explicitly Congratulatory OR Clearly Positive**.

| Sentiment                     | Analysts | Extremely Brief Evidence |
| ----------------------------- | -------: | -------------- |

| Clearly Positive              |          |                |
| Neutral / Information-Seeking |          |                |
| Cautious / Skeptical          |          |                |
| Clearly Negative              |          |                |

**Do not infer broader institutional sentiment from these percentages.**
