OBJECTIVE

Evaluate Coforge Limited's financial performance using ONLY the financial statements and company disclosures available in this Notebook.

The objective is NOT to perform generic ratio analysis.

Instead, extract the small number of financial KPIs that best describe:

• Revenue growth
• Profitability
• Cash conversion
• Employee productivity
• Capital allocation
• Balance-sheet strength

This is a FACT EXTRACTION exercise.

A separate analysis will be conducted later for ROE, ROCE, DuPont analysis, incremental ROCE and valuation.

Always prioritize the latest disclosures.

Use historical periods only to identify trends.

Whenever information is unavailable, write:

NOT SUFFICIENTLY DISCLOSED

Never estimate ratios when sufficient evidence is unavailable.

Use management-reported metrics whenever available.

Only calculate ratios directly from reported financial statements when the required data is available.
